# Project Isabel Website

Free GitHub Pages website for Project Isabel.

## Publish from an iPhone

1. Extract this ZIP in the iPhone Files app.
2. Open `github.com/KNY2342/Project-Isabel` in Safari.
3. Tap **Add file** → **Upload files**.
4. Upload the extracted files and the `assets` folder.
5. Commit the files to `main`.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose **main** and **/(root)**, then tap **Save**.

Your free URL will be:

`https://kny2342.github.io/Project-Isabel/`

Publishing can take several minutes.
