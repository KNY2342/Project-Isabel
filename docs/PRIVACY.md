# Project Isabel Website Privacy — Foundation Draft

This foundation site does not transmit form submissions to a server. The demo early-access form stores the submitted email, role, and timestamp only in the visitor's browser using local storage.

Before public deployment, replace the demo handler with an approved form provider or first-party endpoint and publish a complete privacy notice covering the operator, lawful basis, data retention, subprocessors, user rights, contact method, cookies, analytics, and security controls.
